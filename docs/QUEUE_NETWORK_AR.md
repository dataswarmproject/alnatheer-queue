# ربط أجهزة الفرع — إعداد مجاني تلقائي

بدءًا من 0.4.6، لا تحتاج إلى شراء شهادة HTTPS أو تجهيز ملفات شهادة ومفتاح. شهادة `digital-trendz-internal.cer` المرفقة بالتنزيل لتوقيع البرنامج فقط؛ لا تُستخدم في اتصال الشبكة.

## خادم أُعدّ سابقًا لهذا الكمبيوتر فقط

1. حدّث تطبيق الخادم وتطبيقات المدير والموظفين والكشك إلى 0.4.6 أو أحدث مناسب لنظام Windows. احتفظ بالبيانات وخذ نسخة احتياطية، وأوقف الخدمة بأمان قبل استبدال ملفاتها.
2. على كمبيوتر الخادم نفسه، اختر **استئناف إعداد الخادم** إن ظهر. لا تُنشئ فرعًا أو UUID جديدًا.
3. افتح **إدارة النظام → إعداد اتصال الشبكة**.
4. اختر عنوان الشبكة الثابت للخادم. مثال: `192.168.1.143` والمنفذ `4318`.
5. اترك **طريقة إعداد الشهادة → إنشاء تلقائي · مجاني**. يُملأ العنوان `https://192.168.1.143:4318` تلقائيًا، ولا تظهر حقول شهادة أو مفتاح.
6. أغلق التذاكر المفتوحة ثم اضغط **تفعيل اتصال الشبكة مع حفظ البيانات**. تُفحص الشهادة ويُحفظ احتياطي متحقق قبل إعادة تشغيل قاعدة الفرع نفسها.
7. من الإعدادات، أصدر ملف اقتران جديدًا لكل جهاز وانقله بأمان إلى الجهاز المقصود. اختر **استيراد ملف الاقتران**؛ لا تنسخ مفتاحًا طويلًا ولا تثبّت شهادة في Windows.

للخادم الجديد، اختر عنوان LAN من **اتصال أجهزة الفرع والمركز** أثناء الإعداد، واترك إنشاء الشهادة تلقائيًا. الشهادة ومفتاحها يُنشآن محليًا دون اتصال بالإنترنت. يبقى خيار **استخدام شهادة الشركة** متاحًا للمؤسسات التي لديها شهادات TLS معتمدة.

## الشبكة

- يُثبت مسؤول التقنية عنوان الخادم بحجز DHCP أو عنوان ثابت، ويسمح بالمنفذ من شبكات أجهزة الفرع المعتمدة فقط. لا يفتح التطبيق الجدار الناري أو شبكة عامة تلقائيًا.
- يجب أن يكون العنوان قابلًا للوصول من جهاز الموظف عبر LAN أو مسار VPN. اختر واجهة VPN إذا كان الوصول يتم عبر عنوانها. لا تستعمل `127.0.0.1` على جهاز آخر.
- التهيئة التلقائية تستخدم عنوان IP المختار، وتتحقق الشهادة منه. لا تغيّر العنوان داخل ملف الاقتران إلى اسم أو IP آخر عشوائيًا.
- شاشة HDMI تتبع المدير ولا تحتاج إلى شهادة أو إعداد مستقل. المتصفح العام لا يثق بشهادة الفرع الخاصة تلقائيًا؛ الاتصال من تطبيق النذير المقترن هو المسار المدعوم.

## حفظ الثقة والمفاتيح

لكل فرع جهة إصدار مستقلة. تُحمى مفاتيحها بتشفير Windows لحساب الخادم، وتُخزّن مفاتيح الخادم بصيغة PKCS#8 مشفرة. يتضمن ملف الاقتران الشهادة **العامة** وبصمتها ومعرّف الفرع ومفتاح الجهاز المخصص له؛ لا يتضمن مفتاح توقيع الشهادة أو كلمة حمايته. ملف الاقتران نفسه حساس لاحتوائه على مفتاح جهاز، ويجب نقله إلى الجهاز المقصود فقط.

الثقة بهذه الشهادة تخص اتصال هذا الفرع داخل التطبيق. لا تُضاف إلى مخزن Windows ولا إلى اتصال SARAF أو خدمات الإنترنت. يرفض التطبيق شهادة فرع آخر، أو عنوانًا لا يطابق الشهادة، أو شهادة منتهية.

تُجدّد شهادة الخادم قبل انتهائها عند بدء الخدمة وهي متوقفة، باستخدام جهة الإصدار نفسها حتى تبقى ملفات الاقتران صالحة. لا تُستبدل مفاتيح الجهة تلقائيًا عند تلفها أو فقدها. احتفظ بملفات إعداد التطبيق المحمية على كمبيوتر الخادم؛ النسخ الاحتياطية لقاعدة الانتظار لا تتضمن مفاتيح الشهادة. عند نقل الخادم إلى حساب أو جهاز آخر، يلزم إعداد هوية اتصال جديدة وإعادة اقتران الأجهزة مع الحفاظ على هوية قاعدة الفرع.

لا تُرسل أي مفتاح خاص إلى الدعم أو عبر المحادثات. لا يمكن استخراج المفتاح الخاص من شهادة عامة، ولا تستخدم شهادة توقيع المثبّت مكان شهادة HTTPS.
