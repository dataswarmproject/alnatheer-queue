# النذير لإدارة الانتظار 0.4.6 — Windows 7 SP1 x64

## الملفات والأجهزة

- المثبّت: `alnatheer-queue-0.4.6-windows7-x64.exe`.
- حزمة مسؤول التقنية: `alnatheer-queue-IT-handoff-0.4.6-windows7-x64.zip`.
- المثبّت نفسه للخادم والمدير والموظفين والكشك، وتُختار وظيفة كل كمبيوتر عند أول تشغيل.
- التلفزيون موصول بكمبيوتر المدير عبر HDMI؛ لا يُثبّت عليه تطبيق مستقل.
- إصدار Windows 10/11 0.4.6 متاح بملفه المنفصل `alnatheer-queue-0.4.6-windows-x64.exe`. لا تستخدم مثبّته على Windows 7.

## قبل التثبيت

1. افتح خصائص الكمبيوتر وتحقق من **Windows 7 Service Pack 1 — 64-bit**.
2. جهّز تحديث SHA-2 **KB4474419** وآخر إصدار مناسب منه، وتحديث servicing stack **KB4490628** أو التحديثات التي تحل محلهما، ثم أعد التشغيل. راجع [إرشادات Microsoft](https://support.microsoft.com/en-us/servicing/os/windows/2020/09/2019-sha-2-code-signing-support-requirement-for-windows-and-wsus).
3. تأكد من صحة تاريخ Windows ووقته ومن الثقة بشهادة HTTPS للشبكة. شهادة توقيع البرنامج وشهادة اتصال الفرع شهادتان مختلفتان.
4. اعتمد شهادة Digital Trendz العامة وفق `QUEUE_FREE_SIGNING.md`، بعد مقارنة بصمتها من المصدر المعتمد. يمكن اعتمادها من معالج الشهادات في Windows أو بأداة `trust-internal-publisher.ps1`. لا توزّع أي مفتاح خاص.
5. ثبّت تعريف الطابعة المتوافق مع Windows 7 x64 على الكشك، واختبر طباعة Windows.

لا يحتاج جهاز الفرع إلى تثبيت Node.js أو PostgreSQL منفصلين؛ المثبّت يتضمن محرك التطبيق وقاعدة البيانات المحلية. أدوات تطوير البرنامج تُستخدم على كمبيوتر Windows حديث فقط. أداة الاتصال `test-branch-connection.ps1` الاختيارية تحتاج PowerShell 3 أو أحدث؛ ليست شرطًا لتشغيل التطبيق.

## تشغيل الخادم والكاونتر الأول

1. ثبّت التطبيق على كمبيوتر دائم التشغيل، ثم اختر **خادم الفرع**. يُنشأ معرّف الفرع تلقائيًا ويُحفظ، دون الحاجة إلى SARAF أو كتابة UUID.
2. اختر مجلدًا محليًا فارغًا. لا تختَر مجلد قاعدة قديمة أو مجلد شبكة.
3. من **اتصال أجهزة الفرع والمركز** اختر عنوان LAN ثابتًا، واترك «إنشاء تلقائي · مجاني» لتوليد عنوان HTTPS والشهادة ومفتاحها محليًا. يفتح مسؤول التقنية المنفذ المختار من نطاق LAN/VPN المعتمد فقط. خيار **هذا الكمبيوتر فقط** لا يسمح باتصال أجهزة الموظفين الأخرى.
4. اترك مزامنة SARAF فارغة حتى يُجهّز المركز، ثم اضغط **إنشاء خادم الفرع**. تفتح إدارة الفرع تلقائيًا.
5. افتح **الإعدادات → إضافة خدمة**، مثل «بيع وشراء العملات»، وأدخل بادئة إنجليزية مثل `A`، واترك الخدمة **مفعلة**.
6. اضغط **حفظ إعدادات الفرع**. يحفظ الخدمة وينشئ **كاونتر 1** تلقائيًا عند الإعداد الأول. يبدأ استقبال الكاونتر متوقفًا.
7. للكاونترات الأخرى: **الكاونترات → إنشاء كاونتر**، اختر الرقم والخدمات ثم **حفظ الكاونتر**. لا يمكن حفظ كاونتر دون اختيار خدمة. الحد الأقصى 6.
8. من **الإعدادات → إنشاء وربط الأجهزة** اختر **موظف كاونتر**، وحدد الكاونتر واسم الموظف ومعرّفه، ثم **إصدار مفتاح جهاز → حفظ ملف الاقتران**.
9. ثبّت التطبيق على كمبيوتر الموظف واختر **موظف الكاونتر → استيراد ملف الاقتران**. لا تنشئ خادمًا جديدًا عليه. فعّل استقبال الكاونتر من المدير، ثم اختبر تذكرة صادرة ومطبوعة فعليًا من الكشك.

تفاصيل الكشك والمدير وشاشة العرض والنسخ والمزامنة في `QUEUE_SETUP_AR.md` و`QUEUE_IT_SETUP_AR.md`؛ اختر ملف مثبّت Windows 7 المذكور أعلاه بدل أسماء ملفات Windows الحديثة الواردة فيهما. لا تستخدم `127.0.0.1` للاتصال من كمبيوتر مختلف.

## حفظ البيانات والتحديث

تُحفظ هوية الفرع والاقتران وقاعدة البيانات محليًا. احتفظ بنسخة احتياطية من المدير وبملف معرّف الفرع قبل أي تحديث. لا تنشئ قاعدة ثانية لاستكمال الإعداد، ولا تحذف مجلد البيانات عند إعادة التثبيت.

التحديث في إصدار Windows 7 يدوي بواسطة مسؤول التقنية وباستخدام مثبّت **windows7-x64** فقط. تنزيل وتثبيت إصدارات Windows الحديثة تلقائيًا معطّل لهذا الإصدار حتى يتوفر مسار تحديث مستقل. ملف التحقق `queue-release-windows7-x64.json` منفصل عن ملف التحديث العام.

## نطاق التوافق والتحقق

يستهدف هذا الإصدار Windows 7 SP1 x64 باستخدام Electron 22.3.27، آخر سلسلة Electron تدعم Windows 7. [مرجع Electron](https://www.electronjs.org/blog/windows-7-to-8-1-deprecation-notice). هذه السلسلة ونظام Windows 7 خارج الدعم الأمني؛ يستخدمه مسؤول التقنية على شبكة الفرع المُدارة مع خطة ترقية الأجهزة.

الاختبارات المحلية تُشغّل محرك Electron 22 الفعلي على Windows 11 للتحقق من الإعداد وحفظ الهوية والاتصال والعمليات. لم يُجرَ اختبار فعلي على جهاز Windows 7 في بيئة التطوير هذه. يجب اعتماد جهاز Windows 7 من أجهزة الفرع أولًا، بما فيه الطابعة وHDMI وLAN/VPN والنسخ والاستعادة وإعادة التشغيل، قبل تعميم التثبيت.

إعداد الشبكة التلقائي المجاني وربط الأجهزة موضح في [دليل اتصال الفرع](QUEUE_NETWORK_AR.md). عند استخدامه لا تثبت شهادة HTTPS في Windows؛ استورد ملفات الاقتران الجديدة على التطبيقات المحدثة. أداة فحص HTTPS المعتمدة على مخزن Windows تخص شهادات الشركة اليدوية؛ لا تستخدم فشلها لتقييم شهادة الفرع الخاصة بالتطبيق.
